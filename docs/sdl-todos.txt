SDL3 Binding Implementation TODO
================================

Scope
-----
- Target SDL 3.2.10 headers included with haxe-native.
- Primary implementation file: src/SDL.hx.
- OpenGL bindings needed for context/window integration remain in scope.
- Rendering, GPU, surface, texture, and renderer APIs are explicitly out of scope
  because rendering is implemented with OpenGL.
- SDL_mixer bindings remain separate in src/SDLMixer.hx.


Phase 1: Correct Existing Declarations
--------------------------------------
- [ ] SDL_SetWindowFullscreen: change the return type from Int to Bool.
- [ ] SDL_GL_MakeCurrent: change the return type from Void to Bool.
- [ ] SDL_GL_SwapWindow: change the return type from Void to Bool.
- [ ] SDL_SetWindowPosition: change the return type from Void to Bool.
- [ ] SDL_GetTicks: use UInt64 instead of UInt.
- [ ] SDL_GetWindowSafeArea: accept SDL_Window* instead of an SDL_WindowID.
- [ ] Review display IDs and use SDL_DisplayID/UInt32 consistently.
- [ ] Review SDL_AudioDeviceID and other SDL IDs for platform-appropriate widths.
- [ ] Add and verify the reserved/padding fields in joystick and gamepad event structs.
- [ ] Verify native C struct layout, especially boolean and enum fields.
- [ ] Add ABI and smoke tests that compare representative struct sizes and offsets.

Suggested Implementation Order
------------------------------
1. Properties, errors, timers, and time.
2. Complete event union and event control APIs.
3. Complete window and display APIs.
4. Keyboard, mouse, cursor, text input, and clipboard.
5. Joystick and gamepad.
6. I/O streams, filesystem, storage, and async I/O.
7. Threads, synchronization, atomic operations, timers, and processes.
8. Haptic, audio, sensors, camera, and pen.
9. HID, dialogs, message boxes, tray, locale, power, URL, and platform APIs.


Practical First Milestone
-------------------------
Ship complete editor/application support for:
- Window and display management
- Keyboard and mouse input
- Text input
- Clipboard and primary selection
- Drag and drop
- Controller and gamepad input
- Event filtering and waiting
- Filesystem and I/O streams
- Properties
- Timers
- Errors and logging
- OpenGL context integration
- Dialogs and message boxes

Do not include SDL rendering, GPU, surface, texture, or renderer APIs in this binding file.
