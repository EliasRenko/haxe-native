We have a simple rendering framework using SDL and OpenGL 3.3 used to draw 2d graphics as a priority. The framework is done in haxe with c++ externs to SDL and glad (OpenGL) so we gonna build for native targets. The binary files are in the bin/debug folder and we build using build.hxml. The main functionality of the framework is the easy rendering by extending the DisplayObject class with new display files of our need to create new and easy graphics. All the rendering logic will be written inside those DisplayObjects. At the moment, we are gonna pass the calculated matrix to those objects, calculate the final matrix inside the object and then pass it as uniform for rendering. This would be the basic functionality.
